# Known issues

## Corporate fonts

Корпоративные WOFF2/WOFF/TTF/OTF-файлы и документы, подтверждающие право их распространения,
в репозитории не найдены. До получения официальных файлов используются системные fallback-
гарнитуры. Для display-текста первым выбран доступный в Windows `Bahnschrift Condensed`, затем
`Arial Narrow`. Их метрики отличаются от Figma, поэтому переносы строк и плотность типографики
могут незначительно отличаться. Шрифты из неофициальных источников загружаться не будут.
Hero-заголовок и CTA используют системный Arial для более близкой ширины букв, но точное
соответствие корпоративному шрифту без официальных файлов остаётся недостижимым.

## Hero pause control

На первом этапе у hero-карусели не будет отдельной видимой кнопки паузы. Автосмена будет
останавливаться при hover, focus, скрытой вкладке и полностью отключаться при
`prefers-reduced-motion`. Это принятый компромисс; необходимость отдельного управления следует
повторно оценить по результатам accessibility-проверки.

## Runtime content details

Три hero-slide и их изображения подтверждены предоставленными пользователем Figma-экспортами.
Внутренние node ID слоёв персонажей не были указаны; asset registry поэтому ссылается на source
component Hero Cards `1:1412`, не приписывая файлам выдуманные идентификаторы.

Значения организатора и адреса поддержки в footer пока сохранены как placeholders из макета:
`[юридическое наименование ЦП]` и `[email]`. Они должны быть заменены фактическими данными через
`public/config/site-content.json` до публикации.

## Header visual verification

Точный логотип предоставлен пользователем вручную и подключён локально. Его внутренний Figma
node ID не был указан; в asset registry зафиксирован source frame Navbar `1:1548`. Mobile menu
уточнено по переданному screenshot `375×775`, но отдельные screenshots Navbar `1:1548` и полного
набора Button variants `1:1322` через Figma MCP всё ещё недоступны из-за лимита Starter plan.

## Prize section design access

Figma MCP отклонил запросы метаданных desktop `1:1588` и mobile `1:271` из-за исчерпанного
лимита Starter plan. Пользователь предоставил полноразмерные screenshots секции, конечного
состояния прокрутки и три исходных ассета; реализация сверена с ними. Точные node ID внутренних
слоёв и исходные значения типографики Figma остаются недоступными. Sticky-перекрытие карточек
работает при прокрутке; за секцией теперь следует рейтинг.

## Leaderboard decorative layer

Figma MCP по-прежнему ограничен лимитом Starter plan. Пользователь предоставил точные screenshots
рейтинга, SVG конфетти и аватары, но не отдельный исходник полосатого силуэта внутри podium-
карточек и не node ID внутренних слоёв. Полосы реализованы CSS и могут отличаться от контура в
Figma. При получении точного SVG этот декор можно заменить без изменения контента или разметки.

## CTA fragment targets

Ссылки «Играть сейчас» и «Все результаты» восстановлены с прежними `#play` и `#results`.
Соответствующие целевые разделы пока не реализованы: переход по ссылке меняет фрагмент URL,
но не открывает игру или полный рейтинг. Фактические адреса следует задать в runtime JSON,
когда появятся целевые страницы или секции.

## 8K browser verification

Браузерный инструмент ограничил выставляемую ширину viewport значением 4096 px. На этой ширине
горизонтального переполнения нет и контент рейтинга остаётся ограничен 1200 px, но полноценный
визуальный просмотр при 7680 px не выполнен.

## Mechanics design and scroll range

Figma MCP не открыл узел механики `1:2044` из-за лимита Starter plan. Секция сверена с
предоставленными desktop/mobile PNG и SVG линии. Отдельного mobile-вектора линии нет; её
адаптивная версия воспроизведена CSS без искажения исходного SVG.

После добавления финального CTA мобильная страница получила необходимый запас прокрутки;
подсветка разных показателей повторно проверена на ширине 375 px.

## Final CTA design access

Figma MCP отклонил чтение узла финального CTA `1:2067` из-за лимита Starter plan.
Секция сверена с предоставленными desktop/mobile PNG и тремя исходными ассетами. Точные
параметры внутренних Figma-слоёв и фирменный шрифт остаются недоступными. В mobile-макете
кнопка финального CTA отсутствует, поэтому она скрыта на ширинах до 899 px; другие ссылки
«Начать игру» на странице остаются доступными. Её `#play` по-прежнему не ведёт на игровой
экран до появления соответствующего маршрута.
